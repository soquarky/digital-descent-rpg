# Contributing to The Digital Descent

Thank you for your interest in contributing! This project welcomes contributions of all kinds.

## How to Contribute

### Reporting Bugs
1. Check [existing issues](https://github.com/soquarky/digital-descent-rpg/issues) first
2. Open a new issue with:
   - Clear title
   - Steps to reproduce
   - Expected vs. actual behavior
   - Screenshots if applicable

### Suggesting Features
1. Open an issue with `[Feature Request]` prefix
2. Describe the feature and its value
3. Consider implementation complexity

### Code Contributions

#### Setup
1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/digital-descent-rpg.git
   ```
3. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

#### Development Guidelines

**Code Style**:
- Follow [GDScript style guide](https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_styleguide.html)
- Use tabs for indentation
- Max line length: 100 characters
- Descriptive variable names

**Commit Messages**:
- Use present tense: "Add feature" not "Added feature"
- Reference issues: "Fix #123: Player movement bug"
- Keep first line under 50 characters

**Testing**:
- Test your changes locally
- Ensure no regressions in existing features
- Add unit tests for new systems (if applicable)

#### Pull Request Process
1. Push your branch to your fork
2. Open PR against `main` branch
3. Fill out PR template:
   - What changed?
   - Why?
   - Screenshots/video if visual
4. Wait for review
5. Address feedback
6. Celebrate merge! 🎉

### Asset Contributions

**Art**:
- Pixel art style (16x16 or 32x32 base)
- Color palette consistency
- Include source files (.aseprite, .png)

**Audio**:
- 44.1kHz sample rate
- Loopable tracks preferred
- Include license info

**Writing**:
- Dialogue fits tone (dark, introspective)
- No typos or grammar errors
- Contextual to Dantean themes

## Community Guidelines

- Be respectful and inclusive
- Assume good intentions
- Provide constructive feedback
- Celebrate others' contributions
